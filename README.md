# 청기백기 · AI Motion Play

오픈랩 AI 체험 부스 기획안을 바탕으로 만든 웹캠 기반 청기백기 웹 게임입니다. Vite와 MediaPipe Pose Landmarker를 사용합니다.

## 실행

### 다른 Windows PC에서 설치 없이 실행

1. [최신 릴리스](https://github.com/giwon4197/flag/releases/latest)의 **flag-windows-x64.zip**을 다운로드합니다.
2. **모두 압축 풀기** 후 **START-WINDOWS.bat**를 더블클릭합니다.
3. 자동으로 열린 브라우저에서 참가 정보를 입력하고 카메라를 연결합니다.

Windows x64용 릴리스 ZIP에는 Node.js 런타임과 AI 모델까지 포함합니다. 별도 설치나 모델 다운로드 없이 실행할 수 있습니다. 기록은 실행한 PC의 `data/leaderboard.json`에 새로 저장하며, 기존 참가자 정보는 배포본에 넣지 않습니다. 지급용 파일은 **EXPORT-GIFTICON.bat**로 내보냅니다.

### 소스 코드에서 실행

GitHub의 **Code > Download ZIP**은 실행용 릴리스와 다릅니다. 소스를 내려받았다면 Node.js 24 LTS 설치 후 `START-WINDOWS.bat` 또는 `npm start`를 실행하세요. 첫 실행에서 의존성과 공식 AI 모델을 준비하고 로컬 모델을 사용하는 빌드를 생성합니다. 이후에도 소스를 다시 빌드해 최신 변경을 반영합니다.

개발용 실행:

소스에서 자동 준비 및 실행할 때는 Node.js 24 LTS를 사용하세요.

```sh
npm ci
npm run dev
```

브라우저에서 개발 서버를 열고 **카메라 연결하기**를 누른 뒤 카메라 권한을 허용하세요. 참가 정보를 입력하고 카메라가 연결된 상태에서 **양팔을 올리고 3초 유지하면 자동으로 시작**합니다. 3·2·1 카운트다운 중 팔을 내리거나 인식이 끊기면 취소합니다. 카운트다운은 경기 시간에 포함하지 않습니다. 버튼으로 바로 시작하는 기능도 유지합니다. 카메라는 **HTTPS 또는 localhost**에서만 사용할 수 있습니다. 원격 접속 시 HTTPS로 제공하세요. Chrome / Edge 최신 버전을 권장합니다.

## 참가자 등록과 리더보드

- 화면 하단 **게임 시간**에서 10~600초를 입력합니다(기본 120초). 시작 전에 설정하며 진행 중에는 변경할 수 없습니다. 리더보드는 같은 경기 시간끼리 비교합니다.

- **참가 정보 입력**에서 이름·학번·학과·전화번호를 모두 입력한 뒤 카메라를 연결하고 양팔을 3초 올려 게임을 시작합니다. 게임 중이나 입력창·결과창·리더보드가 열린 동안에는 자동 시작하지 않습니다. 같은 참가자의 다음 자동 시작은 양팔을 한번 내린 뒤 다시 올려야 가능합니다.
- 게임 종료 시 점수를 자동으로 저장합니다. 실패하면 결과창의 **기록 저장 재시도**로 다시 저장할 수 있습니다.
- 리더보드는 학번별 최고 점수 TOP 20을 표시하고, 동점이면 정확도 순으로 정렬합니다. 같은 참가자의 재도전은 기존 최고 기록을 유지합니다.
- 공개 항목은 이름·학과·점수·정확도입니다. 학번·전화번호와 참가자 토큰은 리더보드 응답에 포함하지 않습니다.
- 참가 정보와 기록은 이 PC의 `data/leaderboard.json`에 저장하며 서버를 다시 켜도 유지합니다. 이 경로는 정적 웹 파일 경로 밖에 있고 Git에서도 제외합니다.
- 다음 사람이 참여할 때는 **참가자 변경** 또는 결과창의 **다음 참가자**를 선택합니다. 입력 필드는 새로 비우며, 진행 중인 게임에서는 참가자를 바꿀 수 없습니다.
- 개발 서버와 미리보기에서도 같은 API를 지원합니다. 동일한 데이터 파일에는 한 번에 하나의 서버를 실행하세요. 별도 실행 시 `FLAG_DATA_FILE`로 다른 저장 경로를 지정할 수 있습니다.

### 기프티콘 지급용 파일

전화번호는 `data/leaderboard.json`의 참가자 정보에 저장합니다. 점수는 참가자 토큰으로 연결합니다. 운영자가 파일을 직접 확인하거나, 프로젝트 폴더에서 `npm run export:gifticon`을 실행하면 `exports/gifticon-날짜.csv`를 생성합니다.

CSV에는 경기 시간별 순위, 경기 시간(초), 이름, 학번, 학과, 전화번호, 최고 점수, 정확도가 들어갑니다. 학번·경기 시간별 최고 기록을 선택하고, 연락처는 해당 학번으로 마지막 등록한 정보를 사용합니다. 학번과 전화번호는 엑셀에서 앞자리 0이 유지되도록 텍스트로 출력합니다. 이 파일은 운영자용이며 웹사이트 다운로드 경로에는 공개하지 않습니다.

```sh
npm test        # 팔 판정·명령·난이도 테스트
npm run build  # dist/ 생성
npm run preview
```

## 게임 규칙

- 참가자의 **오른팔 = 청기**, **왼팔 = 백기**입니다. 영상과 관절을 화면 전체에 거울처럼 표시하며, 오른쪽에 청기, 왼쪽에 백기를 배치합니다. 시작 버튼은 중앙, 점수와 남은 시간은 상단에 표시합니다.
- 손목이 어깨보다 충분히 위에 있으면 올림, 아래에 있으면 내림으로 판정합니다. 어깨 근처는 전환 중으로 취급합니다.
- 양팔의 관절이 모두 인식되고, 새 지시가 나온 뒤 지시한 각 팔이 반대 위치에서 목표 위치로 움직인 후 자세를 350ms 유지해야 성공합니다. 복합 지시도 두 팔의 움직임을 각각 확인합니다. 지시하지 않은 팔은 자유입니다.
- 게임 시작 전에 설정한 시간(기본 120초) 동안 진행합니다. 지시 전환, 점수·최고 기록 갱신, 카메라 재연결로 전체 시간이 초기화되지 않습니다. 기본 성공 점수는 100점이며, 연속 성공마다 10점씩 추가합니다(보너스 최대 100점). 참가자 최고 기록은 이 PC의 기록 서버에 저장하며, 상단에는 같은 경기 시간의 현장 최고 기록을 표시합니다.
- 처음 5개 지시는 단일 동작입니다. 이후 복합 지시가 추가되고, 5개 지시마다 제한 시간이 0.5초씩 줄어듭니다(5초 → 최소 2초).
- 다음 지시는 현재 인식된 팔 위치를 반영합니다. 이미 올라간 팔에 다시 올리기를 지시하지 않으며, 복합 지시도 지시하는 양팔이 모두 현재 위치에서 바뀌도록 선택합니다. 양팔이 움직이는 중이거나 인식되지 않으면 자세가 확인될 때까지 다음 지시를 기다립니다.
- 인식이나 카메라 연결이 끊기면 성공 판정을 중단하지만 게임 시간은 계속 흐릅니다. 다른 탭에서 돌아와도 남은 시간이 이어지며, 설정한 시간이 지나거나 게임 종료를 누르면 결과를 표시합니다. 결과의 다시 도전 버튼을 누를 때 새 게임을 시작합니다.
- 정확도는 완료된 지시의 성공 횟수 / (성공 + 시간 초과)입니다. 종료 순간 진행 중이던 지시는 제외합니다.

## AI 모델과 네트워크

WASM 런타임은 `npm ci`의 postinstall에서 `public/wasm/`에 복사되어 앱과 함께 제공됩니다. 모델은 최초 카메라 연결 시 Google 공식 배포 주소에서 다운로드합니다.

```text
https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task
```

`npm start`는 공식 모델을 미리 다운로드하고 로컬 모델 주소로 빌드합니다. Windows 릴리스도 모델을 포함합니다. 개발용 `npm run dev`만 직접 사용하는 경우에는 기본 외부 모델 주소 접근이 필요하거나 아래 방식으로 로컬 주소를 설정해야 합니다.

행사장에서 외부 연결 없이 운영하려면 미리 공식 모델을 내려받아 로컬로 제공하세요.

```sh
mkdir -p public/models
curl -fL https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task -o public/models/pose_landmarker_lite.task
VITE_POSE_MODEL_URL=/models/pose_landmarker_lite.task npm run dev
# 배포용으로 빌드할 때에도 같은 환경변수를 지정합니다.
VITE_POSE_MODEL_URL=/models/pose_landmarker_lite.task npm run build
```

모델과 WASM 생성물은 Git에서 제외합니다. 배포할 때는 `npm ci` 후 빌드하세요. 별도 API 키는 필요하지 않습니다. 카메라 영상은 브라우저의 메모리에서만 처리하며 서버 전송·녹화·저장 기능이 없습니다. 참가 정보와 점수만 로컬 기록 서버에 저장합니다. 카메라 끄기 또는 페이지 종료 시 미디어 트랙을 중지합니다.

## 검증 범위

- 카메라 재시도, 팔 상태·좌우 매핑, 명령 생성, 동작 전환, 시간 설정, 참가자 입력·기록 저장·비공개 필드 제외, 시간별 리더보드와 CSV 내보내기, 3초 자동 시작과 취소·재시작 방지를 검증하는 테스트 30개 통과.
- 프로덕션 빌드와 개발 서버 HTML/WASM 응답 확인.
- 브라우저에서 데스크톱 전체 화면 카메라 영역, 상단 점수판, 백기 왼쪽·청기 오른쪽 배치 및 콘솔 오류 없음 확인.
- 모의 팔 입력으로 2분 세션을 실행하여 연속 성공 시에도 종료 시점이 유지되고, 움직이지 않으면 득점하지 않는 흐름 확인.
- 실제 카메라의 동작 전환 판정은 행사 전 실제 장비·조명·거리에서 확인하세요.
