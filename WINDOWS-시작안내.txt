청기백기 게임 — 다른 Windows PC에서 실행

1. Node.js LTS를 https://nodejs.org/ 에서 설치합니다.
2. 압축 파일을 폴더에 '모두 압축 풀기' 합니다.
3. START-WINDOWS.bat를 더블클릭합니다.
4. 브라우저가 열리면 카메라 연결하기를 누르고 권한을 허용합니다.
5. 오른팔은 청기, 왼팔은 백기입니다. 양팔이 인식되면 게임 시작을 누릅니다.

브라우저가 자동으로 열리지 않으면 http://localhost:5173 을 직접 입력하세요.
게임 중 실행 창을 닫지 마세요. 종료는 실행 창에서 Ctrl+C를 누르세요.
이 패키지는 빌드된 게임을 포함하므로 npm install이 필요하지 않습니다.

카메라와 모델
- 웹캠이 해당 PC에 연결되어 있어야 합니다.
- Chrome 또는 Edge 최신 버전을 권장합니다.
- AI 모델은 첫 연결 시 storage.googleapis.com에서 받으므로 인터넷이 필요합니다.
- 기관/행사장 네트워크가 해당 도메인을 차단하면 관리자에게 허용을 요청하세요.
- 영상은 브라우저 안에서만 처리하며 서버로 보내거나 저장하지 않습니다.

다른 PC에서는 그 PC에서도 이 압축을 풀고 실행해야 합니다.
이 localhost 주소를 다른 PC에 전달하면 연결되지 않습니다.
공유 URL로 접속하려면 dist 폴더를 HTTPS 정적 호스팅에 배포해야 합니다.
