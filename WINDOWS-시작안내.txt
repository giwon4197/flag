청기백기 게임 — 다른 Windows PC에서 실행

1. https://github.com/giwon4197/flag/releases/latest 에서 flag-windows-x64.zip을 받습니다.
2. 압축 파일을 폴더에 '모두 압축 풀기' 합니다. 압축 안에서 바로 실행하지 마세요.
3. START-WINDOWS.bat를 더블클릭합니다. Windows x64용이며 Node.js 설치가 필요 없습니다.
4. 브라우저가 열리면 참가 정보를 입력하고 카메라 권한을 허용합니다.
5. 화면 하단에서 경기 시간을 설정한 뒤 양팔을 올려 3초 유지하면 자동으로 시작합니다.
   팔을 내리면 카운트다운을 취소합니다. 버튼으로 바로 시작할 수도 있습니다.

브라우저가 자동으로 열리지 않으면 http://localhost:5173 을 직접 입력하세요.
게임 중 실행 창을 닫지 마세요. 종료는 실행 창에서 Ctrl+C를 누르세요.
릴리스 ZIP에는 Node.js, 빌드된 게임, WASM, AI 모델이 모두 들어 있습니다.
기존 참가자 정보와 전화번호, 점수는 배포 ZIP에 포함하지 않습니다.
GitHub의 Code > Download ZIP은 소스 코드입니다. 그 파일을 사용한다면 Node.js 24 LTS를 설치하고 START-WINDOWS.bat를 실행하세요. 최초 준비에는 인터넷이 필요합니다.

카메라와 모델
- 웹캠이 해당 PC에 연결되어 있어야 합니다.
- Chrome 또는 Edge 최신 버전을 권장합니다.
- 릴리스 ZIP은 AI 모델을 포함하므로 압축 해제 후 모델 다운로드가 필요 없습니다.
- 영상은 브라우저 안에서만 처리하며 서버로 보내거나 저장하지 않습니다.

다른 PC에서는 그 PC에서도 이 압축을 풀고 실행해야 합니다.
이 localhost 주소를 다른 PC에 전달하면 연결되지 않습니다.
참가 정보와 기록은 실행한 PC의 data/leaderboard.json에 저장합니다.
기프티콘 지급용 CSV가 필요하면 EXPORT-GIFTICON.bat를 실행하세요.
exports 폴더의 CSV에 이름, 학번, 학과, 전화번호, 점수 등이 들어갑니다.
다른 PC의 기록은 자동 합쳐지지 않습니다.
파일을 교체하거나 업데이트할 때 data 폴더를 보관하세요.
